# Security Policy

This repository is ParaLogic's fork of the Frappe Framework. We take security issues in it seriously.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ParaLogicTech/frappe/security/advisories/new)
(Security tab → "Report a vulnerability").

Include the affected version (`frappe/__init__.py` `__version__`), steps to reproduce and the impact you expect.
We'll acknowledge the report, keep you updated, and credit you in the advisory if you'd like.

## Issues that also affect stock Frappe

If the issue also exists in upstream [frappe/frappe](https://github.com/frappe/frappe), please report it to Frappe as
well, following [Frappe's security policy](https://frappe.io/security). Fixes made upstream are brought into this fork.

## Supported versions

Only the `version-15` branch and its latest release receive security fixes.
